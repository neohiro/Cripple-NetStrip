WHY THIS LIST AND THIS ORDER The buttons are lifted from the visitor guide at openstageis.land, because that guide already answers "what does a Second Life visitor do next" and these pages should not answer it differently. Three ordering rules: 1. "Register free" is FIRST. On a phone this group wraps, so the first item is the topmost one and the one a first-time visitor reads first. The stage is only reachable to people who already have an SL account, so that is the real gate. 2. "Teleport" is next, with its web-map fallback rendered beside it unconditionally. secondlife:// is a custom protocol: it silently does nothing in a browser, so the map link is not decoration, it is the only half of the button that works outside the viewer. 3. Booking sits after those two, because booking is meaningless without an account to book from. Every button is a plain . No
