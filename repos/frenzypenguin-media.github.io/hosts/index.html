How these were probed

Method
Plain GET with a browser user agent, up to 8 redirects followed. Never HEAD: several of these hosts answer HEAD with 403 or 405 and look dead when they are not.
Guarded
403, 429, 400 or 999. These mean a bot wall answered, which means the host is up.
Down
Connect refused, TCP timeout past 45 s, or 404 on an otherwise-reachable host.
Broken DNS
The name resolves to a real address but nothing will serve it. Distinguished from down because the fix is a certificate or a CNAME, not a restarted service.
Re-probe
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-hosts.ps1
Single source
_data/hosts.yml. This page, the per-host pages and the status report all read it.
